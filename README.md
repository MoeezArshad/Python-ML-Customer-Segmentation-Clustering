# Python-ML-Customer-Segmentation-Clustering
Customer segmentation using KMeans clustering in Python.

- <b>Shopping Score:</b> A score given to each customer based on how much they spend in the shopping mall
- <b>Annual Income:</b> The annual income for each customer and how the shopping score varies along the income
- <b>Gender:</b> How the Shopping score is divided among the
